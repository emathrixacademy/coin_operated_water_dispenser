Water Refill Vending Machine

Built by eMathrix Technologies · Project EMX-2026-WATERVENDO-01

Research prototype. A coin-operated chilled-water kiosk: ₱1 buys 100 mL, up to ₱20 (2 L) per customer, with automatic change from ₱1 and ₱5 hoppers. This page follows the firmware being tested on the bench unit (31 Oct 2026).

3D simulation and practice

Open the interactive 3D simulation
Operate the machine in the browser: drop coins in the coin slot, choose an amount on the same touchscreen the machine has, put a bottle in the bay and collect the change. Guided lessons teach customers and attendants step by step, and every sale is recorded so the numbers can be checked.

Firmware

Download the bench firmware (31 Oct 2026) Download the main branch
Arduino Mega 2560 firmware (PlatformIO) and the ESP32 touchscreen firmware. The bench firmware is the version running on the unit under test (₱20 / 2 L, green CONFIRM button, measured pour time); it joins the main branch once the team has finished testing. No internet or cloud: the ESP32 display runs a short-range WiFi hotspot for a phone page used on the bench. Build and flash instructions are in the README inside the download.
